# Orindle documentation

Orindle is an all-in-one AI workspace with four products: Chat, Image Studio, Video Studio and Websites. This repository currently contains the frontend-only public website stage. No authentication, payment, database, credit deduction or AI generation behavior is implemented in this stage.

## Working rules

Documentation describes verified reality, not aspirations presented as completed work. A task can be marked complete only after inspection and the relevant checks pass. Research sources include access dates. Product claims, provider availability and model capabilities must remain qualified where they can change. All customer-facing pricing is one-time credit pricing; subscriptions are out of scope.

## Current stage

Prompt 1: public marketing routes, six original articles, responsive navigation, metadata and frontend contracts. The canonical production origin is temporarily assumed to be `https://orindle.com`; see open questions before deployment.
